# Practice JS

A simple Node.js setup for JavaScript practice.

## Structure

- `src/` - main source files
- `src/DSA/` - practice exercises

## Run the project

```bash
npm start
```

## Run a specific exercise

```bash
node src/DSA/01-variables.js
```

## Add more exercises

Create new files inside `src/DSA/` and run them with Node.
